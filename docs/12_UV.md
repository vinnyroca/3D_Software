# ZBrush UVs, Displacement and Substance Painter

## UV Unwrapping

To Unwrap a model in ZBrush

- Set subdivision to lowest level
- Navigate to **ZPlugin** > **UV Master** > **Work On Clone**
<br><br> ![](../assets/images/12/12_uv_01.gif)

This will create a clone of your ZBrush sculpt to work on.

- Select **Create Control Painting** > Use the protect option to paint eras you want to protect from seams, use the attract option to paint areas for seams to be formed. <br><br>![](../assets/images/12/12_uv_02.gif)<br>![](../assets/images/12/12_uv_03.gif)
- Select **Unwrap** > **Check Seams** to see how the seams look. <br><br>![](../assets/images/12/12_uv_04.gif)
- If the seams are in areas that may be distracting, you can rework your protect and attract and unwrap your model again. <br><br>![](../assets/images/12/uv_rework.png)

## Create and use Displacement Maps

Displacement maps are texture maps that can be used to displace geometry while rendering. Unlike normal maps that create the illusion of detail, displacement maps take existing vertices and displace them based on gray scale data.

![](../assets/images/12/dispexample.jpg)

We can create a displacement in ZBrush by using the ZPlugin **Multi Map Exporter**

**To create a displacement map:**

1. Navigate to **ZPlugin** > **Multi Map Exporter**
2. Set **Map Size** to **4096**
3. Navigate to **Export Options** > **Displacement Map** > and turn on **32Bit** and **EXR**
4. Press **Create All Maps** > Save the map in the Source Image of your Maya Project

![](../assets/images/12/12_08.gif)

## ZBrush to Substance Painter

We can use substance painter to bake normal maps and other utility texture maps from our Zbrush model. We can use our high poly model to provide image information to our low poly model.

1. Export a version of your model at the lowest resolution and one version of your model with at least 4 levels of subdivision. <br><br>![](../assets/images/12/12_09.gif)<br><br> ![](../assets/images/12/12_10.gif)
2. Import your low resolution model into a substance painter. <br><br>![](../assets/images/12/12_11.gif)
3. In your **Bake Mesh Map** settings, provide the **High Definition Meshes** setting with your high poly model. <br>![](../assets/images/12/12_12.gif)

## Importing Substance and Displacement Textures into Maya

To import substance painter textures into Maya:

1. Use the **Substance plugin** to bring in your imported textures
2. Replace the height map with the displacement map you exported from ZBrush.
3. Apply this material to the Low Poly model you exported from ZBrush.
   
![](../assets/images/12/12_13.gif)

## Displacement Controls in Maya

Level of displacement is controlled in Maya within the object shape settings. To control displacement, there is a two step process:

1. In your object shape setting in the attribute editor navigate to **Arnold** > **Subdivision**
2. Set **Type** to **catClark** and make sure **Iterations** are set to around 4. This will subdivide your model at run time allowing for more geometry to effectively use the displacement map.
3. In **Displacement Attributes**, make sure **Height** is set to **1.0**. This number might need to vary based on the scale of your object. This value controls the strength of your displacement map.
