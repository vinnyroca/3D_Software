    4a. Polaroid Boolean

    Description

    When learning to model more complex objects, its a good practice to try to recreate models made by other 3D artists. For this exercise, we'll be modeling the back part of this polaroid camera:

    Polaroid Spirit 600 by ZachWilkins1997 on Sketchfab

    Original Polaroid, Spirit 600 (wikimedia.org)

    Tutorial

    1. Create a plane > Subdivisions Width = 1 > Subdivisions Height = 1


    2. Scale plane to be width of back pack of Polaroid


    3. Move vertices of plane to be aligned with back part of Polaroid


    4. Rename plane to “Polaroid Back” > Duplicate plane with Ctrl + D > Rename new plane “Polaroid View Finder” > use Ctrl+H to hide the view finder


    5. Extrude the plane > snap and scale to match the reference


    6. Use Shift+H with View Finder selected to un-hide it


    7. Use the Multi-cut tool to cut bottom edge of view finder > Snap the right edge of view finder to the top of the polaroid back


    8. Delete all faces except for top left corner


    9. Extrude View Finder to match reference


    10. Boolean Union the Polaroid Back and the View Finder


    11. Delete History


    12. Use the Target Weld tool to clean up Topology


    13. Merge all vertices together to prevent any duplicated vertices


    14. Since we won’t see the back or bottom, delete those faces to make the clean up easier


    15. Using the Multi-cut tool to create quadded topology


    16. Extrude out the Viewfinder
